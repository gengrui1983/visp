## 写作约定

- 每篇只聚焦一个机制，覆盖 **v1 实现 / v2 实现 / 关键差异 / 常量与阈值 / 可验证方法**。
- 结论必须给出源码路径（尽量含行号），不做无出处的断言。
- 区分「真实减少发送量」与「仅降低计费 / 非缓存 input 观感」，不混淆两者。
- 篇幅以讲清机制为准，不做防御性展开。
